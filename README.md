# 🌙 Nguyet Tuyen Hoang - Video Background Portfolio with 3D Journey

A stunning video background portfolio featuring an immersive 3D Pagoda Journey section inspired by fantasy RPG games.

## ✨ Features

### 🎬 **Main Portfolio**
- **Video Background**: Beautiful mystical forest with automatic ambient sound
- **Interactive Sections**: About, Projects, Skills, Contact with smooth modals
- **Responsive Design**: Perfect on desktop and mobile devices
- **Clean Interface**: No clutter, just pure elegance

### 🏯 **NEW: My Journey - 3D Pagoda Tower**
- **Fantasy RPG Style**: Inspired by Genshin Impact and Ori and the Blind Forest
- **Interactive 3D Tower**: Navigate through life milestones level by level
- **Game-like Controls**: WASD keys, arrow keys, or click navigation
- **Beautiful Visuals**: Soft lighting, floating particles, magical glow effects
- **Smooth Animations**: Cinematic camera transitions between floors
- **Milestone Stories**: Each floor reveals a chapter of my journey

## 🚀 Quick Setup

1. **Extract** the zip file
2. **Double-click** `index.html`
3. **Enjoy** your portfolio with automatic sound!

**No installation, no dependencies, no terminal commands needed!**

## 🎮 How to Use

### **Main Portfolio**
- **Click buttons** or use **number keys (1-5)** to navigate sections
- **Press 5** or click **"My Journey"** to enter the 3D tower
- **Mobile**: Touch-friendly interface with optimized performance

### **3D Journey Tower**
- **Start**: Click anywhere after the entrance quote
- **Navigate**: Use **W/S** keys, **↑/↓** arrows, or **click the navigation buttons**
- **Exit**: Press **ESC** or click **"Return to Realm"**
- **Mobile**: Touch the up/down buttons to navigate floors
